<project_specification>
  <project_name>Mushroom Cultivation Management System (MCMS)</project_name>

  <overview>
    A comprehensive commercial mushroom farming management system that tracks the full production lifecycle
    from inoculation through harvest and sales. Built using a DSL-First Development methodology blending
    JHipster code generation (structural CRUD) with custom ANTLR/JavaPoet behavioral DSLs (state machines,
    business rules, domain events). The system provides IoT sensor integration, environmental monitoring,
    supply chain traceability (supplier to customer), contamination management, financial dashboards,
    and compliance reporting — all organized around the Batch entity as the central aggregate root with
    a 10-phase lifecycle enforced by a state machine.
  </overview>

    <batch_lifecycle_management>
      - Create new batch with strain, recipe, start date, bag count
      - View batch list with current phase indicator and color coding
      - View batch detail page with full lifecycle timeline
      - 10-phase state machine enforcement:
        - INOCULATION → EARLY_COLONIZATION (guard: substrate fully inoculated)
        - EARLY_COLONIZATION → FULL_COLONIZATION
        - FULL_COLONIZATION → CONSOLIDATION
        - CONSOLIDATION → FRUITING_TRIGGER
        - FRUITING_TRIGGER → PRIMORDIA
        - PRIMORDIA → FRUITING_BODY_GROWTH
        - FRUITING_BODY_GROWTH → HARVEST
        - HARVEST → REHYDRATION_PAUSE (guard: flush count < max)
        - REHYDRATION_PAUSE → HARVEST (rehydrated)
        - HARVEST → COMPLETED (guard: final flush or yield below threshold)
      - Invalid phase transitions blocked with error message
      - Phase execution records created for each transition
      - Domain events emitted on every transition
      - UI shows "Available Actions" buttons based on current phase
      - Batch timeline visualization (horizontal phase progress)
      - Filter batches by phase, strain, active status, date range
      - Search batches by batch code
      - Yield tracking (target vs actual, biological efficiency)
      - Batch notes and completion notes
      - Admin force transition (emergency override with logging)
      - Batch contamination flag indicator
      - View related records (phases, flushes, harvests, costs, materials, contamination)
    </batch_lifecycle_management>
